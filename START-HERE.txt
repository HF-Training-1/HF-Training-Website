HF TRAINING — LIVE SERVICE CODE PACKAGE
Prepared 28 September 2026

WHAT THIS IS
Website code plus an Appwrite backend and automated installer. This is not the
old browser-only demo. It uses real Appwrite sessions and server-side checks.
It is a deployment candidate, not an already-installed or production-certified
system. Your cloud project has not been changed by this package's author.
Do not enrol real students until the installation and live checks are complete.

YOUR NEXT STEP — UPLOAD THE PACKAGE
1. Download this ZIP and extract it on your Chromebook.
2. Open your GitHub repository HF-Training-1 / HF-Training-Website.
3. Choose Add file > Upload files.
4. Upload the extracted contents into the repository root, not the ZIP itself.
   index.html must be at the top level, beside package.json.
   Keep the server, web, setup, tests, docs and .github folders intact.
   In Chromebook Files, use Ctrl+. to show hidden files if .github is missing.
5. Commit to main. The old START-HERE.txt can be replaced.
   The old appwrite-config.js is no longer used. You can delete that file:
   it contains an incorrect project ID from the earlier setup.

IMPORTANT: include .github/workflows/backend.yml and pages.yml. If the upload
picker omits .github, use GitHub Add file > Create new file to create each exact
path. Copy the text from the corresponding file in the package and commit.
Do not paste source code into the GitHub Secrets field or a student form.

NEXT — PUBLISH THE WEBSITE
In the repository, Settings > Pages > Source: choose GitHub Actions.
Go to Actions > Publish HF Training website > Run workflow if it did not run.
Expected address:
https://hf-training-1.github.io/HF-Training-Website/
The page can appear before backend installation, but cannot access records yet.

NEXT — INSTALL THE PRIVATE BACKEND
This step needs a temporary Appwrite setup key. DO NOT send that key in chat,
put it in a code file, or upload it to the repository. It goes only in GitHub's
repository Actions Secrets. The installer uses it from that private location.

In your HF Training Appwrite project, open API Keys and create a temporary key.
Name: HF Training setup
Set a short expiry (for example tomorrow, if available).
Select only these scopes (their display names may use spaces):
users.read
databases.read
rows.read, rows.write
tables.read, tables.write
columns.read, columns.write
indexes.read, indexes.write
buckets.read, buckets.write
functions.read, functions.write

In GitHub: repository Settings > Secrets and variables > Actions >
New repository secret.
Name: APPWRITE_SETUP_KEY
Value: paste the temporary key directly from Appwrite.

Then Actions > Install HF Training backend > Run workflow > main.
The action runs automated checks, creates two private tables and a private
file bucket, prepares your owner profile, and deploys the HF Training API.
It reuses your existing Academies table and existing administrator account.
If it fails, share the error message with all keys/passwords hidden.
Do not loosen permissions or choose public access to resolve an error.
After successful installation, delete/revoke the setup key in Appwrite and
remove the GitHub secret. Runtime uses Appwrite's own short-lived function key.
A future backend update requires a new temporary setup key.
